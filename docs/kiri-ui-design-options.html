Skill inputs

The design constraints before options.

These are the required interface-design checks: domain, color world, signature, and defaults to reject.

Domain

  • Project rows as local workspaces.
  • Agent slots, runtimes, models, terminal modes.
  • JSONL transcripts, diffs, tasks, scratchpad blocks.
  • Keyboard muscle memory and command palette routing.
  • Settings on disk: SQLite, settings.json, local paths.

Color world

  • Editor canvas graphite and tinted charcoal.
  • Mac window chrome, quiet separators, focus rings.
  • Theme accents from Kiri, Vesper, GitHub, Tokyo Night.
  • Terminal status colors: running, warning, destructive.
  • Filesystem literals: muted paths, copyable ids, tokens.

Signature

The session rail: each project stays a horizontal row of agent slots with pips, status, and keyboard targets. The same rail logic should appear in project management and settings previews.

unique to Kiri tile, do not stack

Reject

  • Projects as generic admin modal.
  • Settings as loose card grid.
  • Hero metrics, gradients, mascot, AI sparkle language.
  • Different button styles per surface.
  • Mouse-first controls without keyboard affordance.

Primitive tabs

Agents, scratchpad, and terminals become workspace tabs.

This is the deeper shape: project lanes are still navigated through the corner lens, but the thing you open inside a project is a tab. Agent sessions are tabs. Scratchpad is a shared project/workspace tab. Terminals are detachable tabs, not owned by one agent.

Primitive UI rule Corner Lens rule
Agent tab New agent creates a tab in the active project, not a card in a sidebar. Left/right moves across agent tabs in the highlighted project lane.
Scratchpad tab One shared tab per project or workspace, pinned before disposable agents. Cmd HUD shows it as a stable resource, not part of agent history.
Terminal tab Terminal is a movable project resource; agent terminal is just an attachment. Lens can jump to terminal tabs and show active/running/error state.
Project lane No persistent sidebar; the active project is encoded in toolbar and anchor. Up/down moves lanes, then left/right moves tabs inside the selected lane.
