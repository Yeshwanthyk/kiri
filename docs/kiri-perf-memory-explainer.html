Architecture after the changes
Invariant checks

limit is no longer decorative. It clamps the server detail response to latest timeline rows before parsing into messages and events.

triggerScratchpadSession is the single path for UI and control-plane triggers.

Runtime retained maps now have explicit cleanup calls and a bounded Codex diff-turn guard.

Detail query contract

The detail path now reads from the active thread, unions messages with timeline events, orders newest-first in SQL, applies LIMIT ?, then reverses back to chronological order for rendering.

Source: src/server/db.ts:385, src/server/db.ts:449, src/server/db.ts:495

Shape preservation

The response still returns messages, timelineEvents, and timeline; those arrays are now derived from the returned page, so the client receives coherent data instead of a full historical transcript.

Source: src/server/db.ts:2619

Retained state

Codex runtime state is still process-local, but per-agent maps are cleaned on reset/delete, old thread bindings are pruned when a new thread is remembered, and diff-turn dedupe keys cap at 1,000.

Source: src/server/codex-runtime.ts:52, src/server/codex-runtime.ts:759, src/server/codex-runtime.ts:791

Service layers

DB, settings, and runtime registry now have Effect service layers without forcing a broad rewrite. Existing direct functions remain available, while harnesses can wire services in isolation.
